# Open Location Code test data

`encoding.csv`, `decoding.csv`, `shortCodeTests.csv`, and `validityTests.csv`
are copied unmodified from the Open Location Code project
(<https://github.com/google/open-location-code/tree/main/test_data>, Apache
License 2.0, retrieved 2026-09-18). `tests/olc_official.rs` runs every case.
