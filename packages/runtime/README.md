# packages/runtime

The internal, unpublished Wasm loader shared by the website and the MCP server. Neither surface calls a module any other way.

| File | What |
|---|---|
| `src/module.mjs` | Loads one module and wraps its raw ABI (`invoke`, `invokeBatch`, `manifest`, `version`). The raster module also accepts bounded, user-selected whole files or range-backed files under private handles and returns binary BigTIFF headers and tiles. A Wasm trap becomes an `INTERNAL` error, the instance is recreated, and supplied in-memory state is restored. Runs in browsers and Node. |
| `src/harden.mjs` | Rejects bad input before the core sees it: numbers that overflow, duplicate keys, nesting deeper than 32, strings over 1 MB, oversized payloads |
| `src/files.mjs` | Enforces the 64 MiB whole-file cap and validates range-backed sources up to 16 GiB before private bytes cross into Wasm memory |
| `src/raster.mjs` | Drives raster files through Rust one bounded row-major window at a time for preview, statistics, or sequential BigTIFF export; consumes each result before the next, reports progress, and enforces the 500-megapixel scene contract before pixel work starts |
| `src/node.mjs` | Node host: lazy-loads modules from a directory and routes each tool id to its module. Its asset provider stays offline by default; an explicit opt-in fetches only registry paths from the geoprims asset origin, bounds and verifies every response, and atomically caches verified bytes in the operating system's cache directory. |
| `src/worker-host.mjs` | Node worker host for MCP calls. It enforces timeouts and accepts an optional `AbortSignal` and elapsed-time progress callback on `invoke` and `invokeBatch`. An aborted call resolves to `null`; the worker restarts and queued calls continue. |
| `src/assets.mjs` | Verifies dataset digests and signed tile indexes before providing bytes to a module; Node and browser hosts use the same integrity and pinned-key checks. Both hosts evict corrupt cached bytes and store only verified replacements for offline use. |
| `src/runtime.test.mjs` | Runs every golden vector through Wasm in Node, plus hardening, batch, and unknown-id tests |

The site and MCP release integrity gates check every shipped module's SHA-256 digest against the build. `apps/web/test/browser/determinism.test.mjs` compares exact result bytes for every live golden vector across Chromium, Firefox, WebKit, and Node, including asset-backed calculations. The Wasm import lint rejects host `Math` calls before a module can reach any surface.

The browser worker host is in `apps/web/src/lib/compute.worker.js`. The web client and Node worker host interrupt a running invocation by terminating and replacing its worker; the MCP stdio server forwards progress and cancellation. Both hosts test this boundary with a real long H3 core call and require the canceled call to settle within 100 ms without a partial result.

Local raster files use an ephemeral binary path, not tool JSON. Files up to 64 MiB can be copied into `raster.wasm`; larger TIFFs and COGs are declared by opaque handle and logical length. Metadata inspection, window decoding, and index windows then retry against 64 KiB-aligned ranges requested by the Rust reader, with a 16 MiB per-range limit and a 64 MiB cache limit. Fixed-formula kernels cover the 6 normalized differences, EVI2, SAVI (including its scalar soil factor), dNBR, and 3-band EVI. Band math maps its named rows to an ordered source list, compiles the same capped core AST used by scalar calls, and evaluates that tree for each valid pixel. A 2-band fixed-formula window may explicitly use nearest or bilinear resampling onto either input grid; Rust decodes only the bounded source region needed for that target window, rejects a CRS change, and preserves the target grid and no-data value. Three-band EVI and band math currently require matching grids. The browser reads ranges from the selected `File`; Node reads only an explicit local path. Both worker hosts restore declarations after a restart, and range bytes are discarded after each successful bounded operation. File bytes and names are not written to links, reports, preferences, or caches.

Raster export asks Rust for a complete BigTIFF header, then recomputes and encodes fixed-size float64 tiles in row-major order through the binary Wasm ABI. The shared scene driver awaits each sink write before requesting the next tile, so browsers with the File System Access API keep output memory bounded; other browsers use a Blob fallback. The browser and Node worker hosts preserve the binary envelopes without JSON conversion. Export retains the target dimensions, affine transform, EPSG key, pixel convention, and no-data behavior.

Closing the Node worker host cancels running and queued calls with `null`, clears their timers and abort listeners, and waits for worker termination. Later calls return `null`; repeated `close()` calls share the same termination promise. `src/shutdown.test.mjs` verifies shutdown without requiring built Wasm modules.
