- [x] 3.2 Implement sensor presets and scaling checks; verify the raw-DN and Sentinel-2 scenarios — `raster.scale.reflectance` turns a stored digital number into reflectance with the product's own arithmetic: Sentinel-2 Level-2A as (DN + BOA_ADD_OFFSET) / QUANTIFICATION_VALUE with the baseline 04.00 offset, and Landsat Collection 2 Level-2 as DN x 0.0000275 - 0.2, both read at the issuer (Copernicus SentiWiki and the USGS scale-factor FAQ) and entered in the ledger. It names each preset's bands and what they measure, refuses a digital number of zero because that is no-data in both products, refuses a band name belonging to another sensor, takes the offset and quantification value from the product metadata when they differ, and flags a value that does not scale into reflectance.
